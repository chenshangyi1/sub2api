# DeepSeek 基础计费检查（2026-10-07）

## 本次已修复范围

本站以 USD 余额记账。按照站主的定价规则，国产模型采用供应商人民币价格的数值，不做汇率换算；例如 ¥4/M 在本站作为 $4/M。分组/用户有效倍率继续由站主管理，应用一次。此规则是本站售价政策，不等于上游美元成本。

本次只修改已确认的 SiliconFlow DeepSeek V3.2 基础价：输入 $4/M、输出 $6/M、缓存命中 $0.40/M。普通、Pro 供应商前缀，大小写、v3-2 写法及已允许的纯数字版本后缀使用同一卡。未知后缀继续拒绝。渠道/分组显式价格仍优先。

来源：[硅基流动价格页](https://www.siliconflow.cn/pricing)，2026-10-07 检查的页面可见表格，普通与 Pro V3.2 均为 ¥4/¥6/¥0.40。页面内嵌历史模型元数据含不同价格，不作为此次依据。

根因有两层：原 V3.2 兜底价为 2/8/0，进入模型政策后又被通用 DeepSeek Flash 分支覆盖；动态 USD 目录也没有保护本站人民币数值规则。现在在基础价解析及兜底模型政策两处保护 V3.2，且统一准入识别。

线上最近一次核实的 V3.2 记录为 0.22/0.66/0.007 每百万 tokens；实际扣费在基础合计上乘 0.9。不能用源码初始化的 2/8/0 推断最终账单。

## 验证与部署边界

V3.2 测试先复现了被覆盖到 Flash 的错误，再验证基础价、缓存、有效倍率只乘一次、渠道/分组显式覆盖、其他动态模型不变和未知后缀拒绝。

完整 service 单测包在现有基线上不能编译：重复的 normalizeGroupModelsListConfig、account_stats_pricing_test 的过期字段/参数等。使用 Go 1.26.6、GOEXPERIMENT=jsonv2，以 `go list` 选择该包实际生产 GoFiles，连同相关计费测试文件执行，绕过无关的过期测试文件；这不是完整单测通过。后端 `GOEXPERIMENT=jsonv2 go build ./cmd/server` 成功。

扩大到既有 DeepSeek 测试后还发现下划线供应商前缀归一化及 V4 日期后缀动态价匹配失败；通过 Go overlay 使用修改前 847ce5afa 的 billing_service.go 复现相同失败，确认为既有问题。账号成本统计若使用模型文件定价，也会读此基础卡；它代表本站基础售价，不能据此认为等于供应商实际美元成本。

本次只同步源码，不运行 Docker build、compose up、容器重启、前端发布或数据库写入。新价尚未在线生效。后续其他型号应先建立供应商明确的价卡与分时规则，再测试和单独部署。
