# 角色图片说明

此目录用于存放全局背景角色图片。

## 需要的图片文件

请在此目录中放置以下三张角色图片：

1. **sakura.png** - 樱音角色图片
2. **seina.png** - 星奈角色图片  
3. **sherry.png** - 雪莉角色图片

## 图片要求

- **格式**: PNG（支持透明背景）
- **尺寸**: 建议 600x700px 或更大
- **方向**: 角色应朝向左侧（因为会显示在屏幕右下角）
- **透明度**: 图片会自动设置为30%透明度作为背景
- **风格**: 动漫/插画风格，与您的品牌风格一致

## 使用说明

角色会自动每5秒切换一次，作为全局背景装饰出现在所有页面的右下角。

如需修改角色信息或添加更多角色，请编辑：
`src/components/modelPlaza/CharacterDisplay.vue`
